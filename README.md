# Entrepreneur Hub

AURIXEN

Système central privé de gestion, d’organisation et de pilotage entrepreneurial

1. VISION GÉNÉRALE

Aurixen est un site web privé personnel permettant de centraliser l’ensemble de mes projets entrepreneuriaux au même endroit.

Le site est principalement utilisé sur mobile. Le mobile-first n’est donc pas une adaptation secondaire : il doit guider la conception de toute l’interface. L’expérience doit être pensée d’abord pour un écran de smartphone, avec navigation tactile, boutons facilement accessibles, textes lisibles, cartes compactes, gestes et actions rapides. La version desktop doit ensuite s’adapter proprement à cette architecture mobile.

Le site doit permettre de :

gérer plusieurs projets indépendants ;

centraliser les idées, stratégies, notes et informations ;

suivre les performances et les données en temps réel ;

connecter des services externes comme Pinterest et Gumroad via leurs API officielles ;

synchroniser automatiquement les données externes dans Aurixen ;

organiser les contenus et fichiers ;

gérer les calendriers ;

rechercher rapidement n’importe quelle information dans le site ;

disposer d’un espace de travail différent pour chaque projet ;

donner à chaque projet sa propre identité visuelle et ses propres fonctionnalités.

Aurixen doit donc fonctionner comme un centre de contrôle personnel, dans lequel chaque projet possède son propre environnement tout en restant accessible depuis une interface générale commune.

Toutes les intégrations externes doivent être conçues avec une architecture sécurisée : les mots de passe ne doivent jamais être demandés ni stockés par Aurixen. Les connexions doivent utiliser les mécanismes d’authentification officiels des services concernés et les secrets/API tokens doivent rester côté serveur, dans des variables secrètes.

1.1 PRIORITÉ MOBILE

Le site doit être conçu mobile-first, car son utilisation principale se fera depuis un iPhone ou un autre smartphone.

Principes obligatoires :

interface parfaitement utilisable avec une seule main ;

navigation mobile simple et persistante ;

boutons et zones tactiles suffisamment grands ;

informations importantes visibles sans devoir ouvrir de nombreux menus ;

cartes et tableaux adaptés aux petits écrans ;

graphiques analytics lisibles sur mobile ;

possibilité d’effectuer les actions fréquentes en très peu de touches ;

fenêtres et formulaires optimisés pour le clavier mobile ;

chargement rapide ;

interface responsive complète pour tablette et desktop, mais conçue à partir de la version mobile.

Éviter les interfaces desktop simplement réduites sur smartphone.

2. PAGE D’ACCUEIL AURIXEN

La page d’accueil représente le hub central d’Aurixen.

Sélection des projets

L’utilisateur doit pouvoir choisir le projet sur lequel il souhaite travailler.

Exemples de projets actuellement prévus :

Léo Valen

Projet autour des produits éducatifs, ebooks, Pinterest, stratégies marketing et analytics.

Danse du Lion

Projet autour des prestations de danse du lion pour les restaurants chinois.

D’autres projets devront pouvoir être ajoutés plus tard.

Design de la page d’accueil

La page d’accueil doit avoir un design propre, premium et moderne correspondant à l’univers Aurixen. Noir et or premium, style marque de luxe. 

Elle doit permettre d’accéder rapidement aux différents projets sans rendre l’interface chargée.

Chaque projet doit pouvoir avoir :

son propre nom ;

son propre visuel ;

sa propre identité graphique ;

ses propres fonctionnalités ;

son propre environnement.

Ajouter aussi un espace d’écriture pareil que dans les project.

3. CALENDRIER GLOBAL AURIXEN

La page d’accueil doit contenir un calendrier commun à tous les projets.

Ce calendrier permet de visualiser globalement les événements et activités liés aux différents projets.

Il doit permettre de :

créer manuellement un événement ;

modifier un événement ;

supprimer un événement ;

consulter rapidement les événements ;

voir les événements associés à différents projets ;

distinguer les projets visuellement.

Le calendrier global doit servir de vision d’ensemble de l’activité entrepreneuriale.

4. RECHERCHE GLOBALE

Aurixen doit posséder une barre de recherche présente sur le site.

Elle doit permettre de rechercher rapidement dans l’ensemble du système.

La recherche doit pouvoir retrouver notamment :

des idées ;

des notes ;

des stratégies ;

des pins ;

des produits ;

des restaurants ;

des fichiers ;

des événements ;

des informations stockées manuellement.

L’objectif est de pouvoir retrouver une information sans devoir parcourir chaque espace manuellement.

5. SYSTÈME DE PROJETS

Chaque projet possède un espace indépendant.

Un projet est donc plus qu’un simple dossier : il possède son propre environnement de travail.

Chaque projet peut avoir :

un design différent ;

ses propres couleurs ;

ses propres fonctionnalités ;

ses propres données ;

ses propres calendriers ;

ses propres espaces d’écriture ;

ses propres systèmes de classement.

7. CENTRE DE CONTRÔLE LÉO VALEN

L'espace Léo Valen doit centraliser tout ce qui concerne le projet.

Il doit notamment permettre de stocker :

toutes les idées ;

toutes les stratégies ;

toutes les réflexions ;

les plans marketing ;

les idées de contenu ;

les idées de produits ;

les informations importantes liées au projet ;

les notes personnelles de travail.

Aucune information ne doit nécessiter d'être conservée dans plusieurs endroits différents.

8. SUIVI DES VENTES EN TEMPS RÉEL

Le projet Léo Valen doit comporter une zone permettant de consulter les ventes en temps réel.

Cette zone doit servir de tableau de bord commercial.

Elle doit permettre de voir rapidement :

les ventes ;

l'évolution des ventes ;

les performances ;

les données importantes liées aux produits.

L’objectif est d’avoir une vision immédiate de l’activité commerciale.

9. ANALYTICS PINTEREST EN TEMPS RÉEL

Le projet Léo Valen doit également intégrer les analytics du compte Pinterest.

L’objectif est de pouvoir consulter directement depuis Aurixen les performances du compte Pinterest.

Les données importantes doivent pouvoir être centralisées dans le tableau de bord.

10. BIBLIOTHÈQUE DES PINS

Créer un espace spécialement destiné aux pins Pinterest.

Cet espace doit permettre de stocker et consulter :

tous les pins créés ;

tous les pins déjà publiés ;

les informations associées à chaque pin ;

leurs performances.

Il doit être possible de distinguer visuellement :

Pins créés mais non publiés

Avec un code couleur ou une icône spécifique.

Pins publiés

Avec un autre code couleur ou une autre icône.

La distinction doit être immédiatement compréhensible visuellement.

11. FICHE DÉTAILLÉE D’UN PIN

Lorsque l’on clique sur un pin, une fiche détaillée doit s’ouvrir.

Elle doit afficher notamment :

l’image du pin ;

son statut ;

sa date de publication ;

le produit associé ;

ses analytics ;

sa note ;

les autres informations utiles.

12. PRODUIT ASSOCIÉ AU PIN

Chaque pin doit pouvoir être associé à un produit.

Les produits actuellement prévus sont :

Produit A ;

Produit B-1 ;

Produit B-2 ;

Produit B-3 ;

Produit C.

Cette information doit être visible directement depuis la fiche du pin.

Elle doit également pouvoir être utilisée pour analyser les performances des différents produits.

13. NOTE / SCORE DES PINS

Chaque pin doit recevoir une note calculée ou attribuée selon plusieurs facteurs.

Cette note ne doit pas nécessairement dépendre uniquement d’une métrique.

Elle doit pouvoir prendre en compte :

les analytics ;

la performance globale ;

l'engagement ;

la portée ;

les clics ;

d’autres facteurs importants ;

éventuellement la comparaison avec les autres pins.

L’objectif est d’obtenir un score permettant de déterminer rapidement quels sont les meilleurs pins.

14. CLASSEMENT DES PINS

Les pins doivent pouvoir être classés :

du meilleur au moins performant.

Il doit être possible de consulter différents classements.

Classement général

Tous les pins classés selon leur performance.

TOP 5 hebdomadaire

Les 5 meilleurs pins de la semaine.

TOP 1 mensuel

Le meilleur pin du mois.

L’objectif est d’identifier rapidement :

ce qui fonctionne ;

les formats les plus performants ;

les sujets les plus performants ;

les produits les plus performants ;

les tendances à reproduire.

15. ESPACE D’ÉCRITURE INTELLIGENT

Léo Valen doit disposer d’un espace permettant d’écrire librement.

Cet espace sert notamment à :

noter des idées ;

écrire des stratégies ;

écrire des réflexions ;

préparer du contenu ;

stocker des textes ;

conserver des informations temporaires ou permanentes.

Fonction essentielle : copie rapide

Il doit être possible de copier très facilement le contenu écrit.

L'objectif est d'éviter d'avoir à :

ouvrir une note ;

sélectionner tout manuellement ;

copier ;

revenir en arrière.

L'interface doit permettre de copier directement une note ou son contenu avec une action simple.

Par exemple, chaque note pourrait avoir un bouton :

COPIER

qui copie immédiatement l'intégralité du contenu.

16. STOCKAGE DE FICHIERS

Aurixen doit contenir un espace permettant de stocker des fichiers.

L’objectif est de pouvoir centraliser les documents liés au projet.

Les fichiers doivent pouvoir être :

ajoutés ;

consultés ;

organisés ;

déplacés ;

classés ;

rangés manuellement.

Le système doit rester suffisamment flexible pour permettre une organisation personnelle.

17. ORGANISATION MANUELLE DES FICHIERS

L’utilisateur doit pouvoir organiser les fichiers lui-même.

Il doit être possible de créer une structure personnalisée adaptée à sa manière de travailler.

Aurixen ne doit donc pas imposer une organisation rigide.

18. CALENDRIER LÉO VALEN

Léo Valen doit également disposer de son propre calendrier.

Ce calendrier doit être indépendant du calendrier général tout en pouvant être intégré à celui-ci.

Il doit être facilement remplissable manuellement.

Il doit permettre de planifier par exemple :

publication de pins ;

création de contenus ;

travail sur les produits ;

tâches ;

stratégies ;

événements ;

autres activités liées à Léo Valen.

L’objectif est d’avoir un calendrier très simple à remplir et à consulter.

PROJET 2 — DANSE DU LION

19. IDENTITÉ VISUELLE

Le projet Danse du Lion doit avoir un design complètement différent du projet Léo Valen.

Son univers visuel doit être inspiré de :

la culture chinoise ;

le Nouvel An chinois ;

les couleurs traditionnelles ;

l’univers festif ;

la danse du lion.

Le projet doit donc avoir une identité graphique propre et immédiatement reconnaissable.

20. ESPACE DANSE DU LION

Le projet doit centraliser les informations liées aux restaurants et aux prestations de danse du lion.

L’élément central du projet est une base de données de restaurants.

21. FICHES RESTAURANTS

Chaque restaurant doit posséder sa propre fiche.

La fiche du restaurant doit pouvoir afficher :

nom du restaurant ;

emplacement ;

numéro de téléphone ;

adresse email ;

site web ;

style de cuisine ;

informations spécifiques ;

parking à proximité ;

taille du restaurant ;

autres informations utiles.

Tous les restaurants seront des restaurants chinois.

22. INFORMATIONS PERSONNALISÉES

Il doit être possible d'ajouter manuellement des informations supplémentaires sur chaque restaurant.

Le système ne doit donc pas être limité à des champs prédéfinis.

L’utilisateur doit pouvoir écrire ses propres informations et observations.

Exemples potentiels :

contact particulier ;

informations sur le propriétaire ;

intérêt pour la prestation ;

informations pratiques ;

particularités du lieu ;

notes personnelles.

23. DISPONIBILITÉS POUR LES DANSES DU LION

Chaque fiche restaurant doit contenir une zone spécifique permettant de gérer les disponibilités pour les danses du lion.

Cette zone doit permettre d’associer :

une date ;

une heure ;

un restaurant ;

une disponibilité.

L’objectif est de savoir rapidement quelles dates sont disponibles pour chaque restaurant.

24. CALENDRIER DANSE DU LION

Le projet doit posséder un calendrier commun spécifique à la Danse du Lion.

Ce calendrier doit permettre de visualiser :

les restaurants ;

les dates ;

les heures ;

les disponibilités ;

les événements planifiés.

L’objectif est d’avoir une vision globale des prestations potentielles et planifiées.

Il doit être possible de voir rapidement :

DATE → HEURE → RESTAURANT → DISPONIBILITÉ

25. ESPACE D’ÉCRITURE DANSE DU LION

Le projet Danse du Lion doit également posséder son propre espace d’écriture.

Il doit permettre de conserver :

idées ;

stratégies ;

notes ;

informations sur les restaurants ;

observations ;

organisation des prestations ;

autres informations utiles au projet.

Le fonctionnement doit être similaire au système d’écriture de Léo Valen, tout en étant intégré au design du projet Danse du Lion.

27. PRINCIPE FONDAMENTAL D’AURIXEN

Aurixen doit fonctionner selon une logique simple :

UN SEUL SITE → TOUS LES PROJETS → UN ESPACE ADAPTÉ À CHAQUE PROJET

Le système doit permettre de passer rapidement d’un projet à un autre sans perdre l’organisation globale.

Chaque projet conserve cependant :

son identité ;

son design ;

ses fonctionnalités ;

ses données ;

son organisation.

Aurixen devient ainsi le centre de pilotage personnel de l’ensemble de l’activité entrepreneuriale.

28. OBJECTIF FINAL

L'objectif n'est pas seulement de créer un espace de stockage.

Aurixen doit devenir un véritable système de travail personnel permettant de :

PENSER → ORGANISER → CRÉER → ANALYSER → DÉCIDER → PLANIFIER → EXÉCUTER

Tout ce qui concerne les projets entrepreneuriaux doit pouvoir être centralisé dans cet environnement.

L'utilisateur doit pouvoir ouvrir Aurixen et comprendre immédiatement :

quels projets existent ;

ce qui se passe actuellement ;

ce qui doit être fait ;

quelles données sont importantes ;

quels contenus fonctionnent ;

quelles idées ont été enregistrées ;

quelles activités sont planifiées ;

où se trouvent les fichiers ;

et quelles sont les performances de chaque projet.

Aurixen doit donc être pensé comme un OS entrepreneurial privé et évolutif, capable d'accueillir de nouveaux projets et de nouvelles fonctionnalités au fil du développement de l'activité.
